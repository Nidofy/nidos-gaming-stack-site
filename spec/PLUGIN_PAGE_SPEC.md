## 事实与发布边界

- 本地包为 `0.7.0-preview.3`；GitHub 根 README 仍介绍 0.6.1。版本及核对日期保存在独立版本资料中，不推断公开发行日期。
- 页面标记开发中 / 内部预览。核心玩法与 0.7 预览故事、三连棋分开，不将尚未批准的梦境门庭资产用作宣传。
- 安装基线：官方 DSH 0.2.1-rc.2、Windows x64；本地 tgz 通过 Plugins → Add plugin 安装并完整重启。源码构建依赖 Node 24+ 及仓库说明中的工具环境。
- 不提供未经确认的公开下载地址，不上传本地 tgz，不自动发布 npm 或网站。公开安装包地址待作者正式发行后接入 release 数据。
- 明确离线规则模拟、不需要 API key、没有离线推进；与 Git/Hg 共存、与 Live2D 互斥。升级前备份，不能直接降级覆盖新存档。
